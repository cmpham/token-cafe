# Pose atlas generation

Built-in imagegen, 2026-10-27. One call per character with the shared prompt and character description below. These generated fan-art sheets replace static collected sprites at runtime.

Create a production game animation sprite atlas: exactly 4 columns by 4 rows, 16 equal square cells, transparent background. One character repeated in all 16 cells. Tiny authentic 24x28 pixel art scaled up with hard square pixels, flat limited palette and dark one-pixel outline, no gradients, no lighting, no lettering, no cell borders, no background or shadows. Camera 3/4 front view facing viewer and slightly right, like a patron at a desk below them. Compact chibi anatomy. Each frame stays inside its equal cell with margins. Keep head/body proportions identical between adjacent animation frames. Same fixed seat/hip position centered at 75 percent cell height for first 12 cells. No chairs, desks, laptops or keyboard drawn; furniture is rendered by game. Seated poses MUST have bent tucked hindlegs, seated haunches, folded wings, torso leaning forward toward desk at bottom, front paws reaching forward/down onto a keyboard at lower center. Do not use an upright standing pose for seated frames. Adjacent frames show actual limb articulation, not whole-image translation.
